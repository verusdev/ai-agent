# AI Агент

ИИ-агент уровня Manus: ставите задачу — он сам разбивает её на шаги, выполняет их инструментами и собирает результат в артефакты.
Ключевая особенность: **работает на бесплатных моделях** — локально через Ollama без ключей и без интернета, либо на облачных API с бесплатным лимитом.

Laravel 13 + SQLite, Blade, собственный фронтенд без сборки и без CDN.

---

## Как это работает

```
задача → план (update_plan) → модель решает, что делать
       → вызов инструмента (файл / поиск / график / расчёт)
       → результат инструмента возвращается в модель
       → агент повторяет, пока задача не закрыта
```

Одна итерация агента — один вызов модели. Клиент дёргает `POST /agents/{id}/tick` и получает весь новый
статус задачи: план, шаги, сообщения и артефакты. Поэтому очередь и воркер не нужны — агент работает
даже на встроенном сервере `php artisan serve`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `update_plan` | Ведёт план задачи: шаги и их статусы `todo → doing → done` |
| `web_search` | Поиск в интернете без API-ключа (DuckDuckGo) |
| `web_fetch` | Скачивает страницу и отдаёт текст без разметки |
| `write_file` / `read_file` / `list_files` | Файлы в рабочей папке задачи |
| `create_document` | Документы `md`, `html`, `csv`, `txt`, `json` → в галерею результатов |
| `make_chart` | Графики `line` / `bar` / `donut` в самодостаточном SVG |
| `calculate` | Точные расчёты: рекурсивный спуск, без `eval` |
| `run_code` | `python` / `php` / `node`. **Выключен по умолчанию** (`AGENT_SHELL_ENABLED=false`) |

Все файловые инструменты ограничены папкой задачи `storage/app/private/agents/{uuid}` — выход вверх по `..` блокируется.

## Бесплатные модели

Один клиент `LlmClient` говорит на OpenAI-совместимом API, поэтому подходят и локальные, и облачные провайдеры.
Пресеты добавляются одной кнопкой в разделе **«Модели и ключи»**.

### Локально — без ключей и без интернета

```bash
ollama serve
ollama pull llama3.1:8b        # или qwen2.5:7b-instruct, gemma2:9b, phi4
```

Провайдер **Ollama**: `http://127.0.0.1:11434/v1`, API-ключ не нужен. Есть пресет **LM Studio** (порт 1234).

### Облачно — по бесплатному ключу

| Провайдер | Ключ | Модели |
|---|---|---|
| **Groq** | console.groq.com/keys | `llama-3.3-70b-versatile`, `llama-3.1-8b-instant`, `qwen-2.5-32b`, `deepseek-r1-distill-llama-70b` |
| **OpenRouter** | openrouter.ai/keys | модели с суффиксом `:free` — `deepseek/deepseek-chat-v3-0324:free`, `google/gemini-2.0-flash-exp:free`, `qwen/qwen-2.5-72b-instruct:free` |
| **Google AI Studio** | aistudio.google.com/apikey | `gemini-2.5-flash-lite`, `gemini-2.0-flash`, `gemini-2.5-pro` |

Ключи шифруются в базе (`encrypted` cast) и никогда не выводятся в HTML — только маска `gsk-••••••••alue`.
Любой другой OpenAI-совместимый endpoint (Together, Fireworks, llama.cpp, vLLM) добавляется формой вручную.

### Модели без native tool calling

Бесплатные модели часто не умеют вызывать инструменты нативно. Тогда `LlmClient` переключается на
текстовый протокол (`ToolProtocol`): в системный промпт добавляется инструкция, а модель отвечает блоком

```
<tool_call>{"tool": "write_file", "args": {"path": "a.md", "content": "…"}}</tool_call>
```

Парсер понимает обёртку ```json``` и строку аргументов. Поэтому агент работает практически с любой моделью —
переключать ничего не нужно, достаточно снять галочку «умеет вызывать инструменты» в настройках провайдера.

## Установка

```bash
git clone https://github.com/verusdev/ai-agent.git
cd ai-agent

composer install
cp .env.example .env
php artisan key:generate

touch database/database.sqlite
php artisan migrate --seed      # провайдеры + демонстрационная задача
php artisan serve
```

Открыть http://127.0.0.1:8000 → **«Модели и ключи»** → добавить провайдера → **«Новая задача»** → **«Запустить»**.

Модель можно проверить кнопкой «Проверить связь» — приложение делает `GET /models` и подставляет
в список реально доступные модели.

## Десктопное приложение

В папке `desktop/` лежит Electron-обёртка: окно приложения показывает тот же интерфейс, а встроенный
PHP-сервер поднимается сам — запускать Laravel вручную не нужно.

```bash
cd desktop
npm install
npm start
```

При первом старте приложение занимает свободный порт (по умолчанию 8124), поднимает
`php artisan serve`, дожидается готовности `/up` и открывает окно.

Что добавляет десктоп-режим:

- **нативное меню и трей** — «Новая задача» (Ctrl+N), «Модели и ключи» (Ctrl+K), перезапуск сервера, открытие папки с артефактами;
- **системные уведомления**, когда агент закончил задачу или упал с ошибкой;
- **кнопка «📂 Папка»** в блоке артефактов — открывает каталог задачи в проводнике;
- **запоминание размеров и положения окна**, второй экземпляр не запускается;
- **внешние ссылки** открываются в системном браузере, а не внутри окна.

PHP ищется автоматически. На Windows интерпретатор часто доступен как `.cmd`-шим (ServBay, XAMPP, Scoop),
а Node такие файлы не запускает — поэтому приложение спрашивает у самого PHP его настоящий путь
(`PHP_BINARY`). Если PHP стоит нестандартно, укажите полный путь в файле `desktop/php-path.txt`
или в переменной окружения `AI_AGENT_PHP`.

### Сборка установщика

```bash
cd desktop
npm run dist        # AI-Agent-1.0.0-x64.exe (NSIS) + portable-версия
npm run dist:dir    # только распакованная сборка, быстрее для проверки
```

Сборка кладёт Laravel-приложение целиком (`app`, `vendor`, `storage`, `.env`) в ресурсы исполняемого файла,
поэтому установленная программа работает автономно.

## Запуск из командной строки

```bash
php artisan agent:run            # последняя задача
php artisan agent:run 3          # по id
php artisan agent:run <uuid>     # по uuid
```

## Тесты

```bash
php artisan test
```

30 тестов: агентный цикл целиком (план → инструмент → итог), текстовый протокол вызова инструментов,
обработка ошибок модели и инструментов, запрет выхода за пределы песочницы, артефакты, настройки
провайдеров и шифрование ключа, калькулятор (включая отказ от `eval`).

## Безопасность

- API-ключи шифруются и не отдаются в разметку.
- Файлы задачи изолированы в песочнице, выход за её пределы блокируется.
- Калькулятор — рекурсивный спуск, никакого `eval` и вызова функций.
- `run_code` выключен по умолчанию, при включении работает только с белым списком бинарников и таймаутом.
- Веб-интерфейс без авторизации — приложение рассчитано на локальный запуск.
